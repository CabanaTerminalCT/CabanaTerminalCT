# 🤝 Contribuindo com a Cabana Terminal

## Antes de tudo

Leia o [manifesto](./MANIFESTO.md). Se você concorda com ele, bem-vindo.

## Formas de contribuir

- Corrigir erro em trilha/writeup
- Adicionar exercício ou task nova
- Melhorar explicação que tá confusa
- Traduzir conteúdo
- Reportar bug
- Sugerir trilha nova
- Escrever writeup de CTF

## Como abrir uma issue

1. Verifica se já não existe uma issue sobre isso
2. Usa o template adequado
3. Descreve com clareza: o que, por quê, como reproduzir

## Como mandar um PR

1. Forka o repo (ou cria branch, se for membro)
2. Nome da branch: `tipo/descricao-curta`
   ex: `fix/typo-trilha-python`, `feat/exercicio-loops`
3. Commits pequenos e descritivos
4. Abre o PR explicando o que mudou e por quê
5. Aguarda review — qualquer membro pode aprovar

## Como virar membro

- Contribuiu com algo relevante? Pede pra entrar.
- Não tem hierarquia de entrada.
- Membros ganham permissão de write nos repos.

## Estilo de commit (sugestão, não regra)

- `feat:` nova funcionalidade/conteúdo
- `fix:` correção
- `docs:` documentação
- `refactor:` reorganização
- `chore:` manutenção

Ex: `feat: adiciona exercício sobre listas em python`

## O que NÃO rola

- Gatekeeping ("isso é muito básico pra tá aqui")
- Plágio de writeup de outro CTF sem crédito
- Conteúdo pago/depredador
- Assédio (ver CODE_OF_CONDUCT)

## Dúvidas?

Abre uma issue com a tag `duvida`. Ninguém vai te julgar.
