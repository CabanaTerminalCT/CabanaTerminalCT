# Capitulo 11 - Projeto final

Capstone. O aluno sai com um projeto real no GitHub da cabana.
Neste capitulo a **CabanaTerminal** acompanha voce do problema ate o PR.

> Nao e mais exercicio. E projeto. Aqui a gente constroi de verdade.

| 105 | Persistencia em JSON | dados |
| 106 | Trata erros | robustez |
| 107 | Modulariza arquivos | arquitetura |
| 108 | Testa manualmente | QA |

## `> cat como_usar.md`

1. Leia o enunciado comentado no topo de cada `.py`.
2. Este capitulo e guiado: cada task entrega uma parte do projeto final.
3. Ao final, voce abre um PR no GitHub da cabana.

`[root@cabana]# git commit -m "feat: projeto final" && git push`
