## `> cat como_usar.md`

1. Cada capitulo e uma pasta com um `README.md` e as tasks em `.py`.
2. Em cada `.py` o enunciado vem comentado; voce escreve o codigo embaixo de
   `# >>> SEU CODIGO AQUI <<<`.
3. Rode com `python3 nome_do_arquivo.py`.
4. Faca na ordem. Cada capitulo usa o anterior.
