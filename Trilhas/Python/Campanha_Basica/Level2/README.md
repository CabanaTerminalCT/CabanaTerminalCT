# Nivel 2 - Loops e Repeticao

Bem-vindo(a) ao **Nivel 2** da trilha de Python da **CabanaTerminal**.
Aqui o computador para de fazer uma coisa so e comeca a repetir trabalho
pra voce. Sem chefe. Sem dono. Sem patron. So loop.

## `> ./listar_desafios`

| # | Nome | Nivel | Conceito | O que faz |
|---|------|-------|----------|-----------|
| 011 | Eco infinito | 2 estrelas | `while` | Repete uma mensagem N vezes ate a condicao parar |
| 012 | Contagem regressiva | 2 estrelas | `while` + `-=` | Conta de 10 ate 0 e imprime "foguete!" |
| 013 | Menu do terminal | 2 estrelas | `while` + `input` | Menu que repete ate o usuario digitar "sair" |
| 014 | Tabuada | 2 estrelas | `for` + `range` | Imprime a tabuada de um numero (1 a 10) |
| 015 | Soma acumulada | 3 estrelas | `for` + acumulador | Soma 1 ate N e mostra o total |
| 016 | Caca-vogais | 3 estrelas | `for` + string | Conta quantas vogais tem numa palavra |
| 017 | Fuga do loop | 3 estrelas | `break` | Loop que para quando achar um numero secreto |
| 018 | Pula o 7 | 3 estrelas | `continue` | Conta de 1 a 20, pulando multiplos de 7 |
| 019 | Piramide de asteriscos | 4 estrelas | `for` aninhado | Desenha uma piramide com `*` de altura N |
| 020 | Mini-projeto: quiz do terminal | 4 estrelas | tudo junto | Quiz de 5 perguntas com pontuacao no final |

## `> cat como-usar.md`

1. Faca na ordem. Cada desafio usa o que veio antes.
2. Leia o enunciado inteiro antes de digitar.
3. Teste rodando de verdade: `python3 nome.py`.
4. Travou? Abre uma issue com a tag `duvida`.
