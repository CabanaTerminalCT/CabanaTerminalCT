# Capitulo 3 - Strings

Texto e o tipo mais manipulado da vida real. Sem isso, nada de arquivo, JSON
ou web. Neste capitulo a **CabanaTerminal** te ensina a domar strings.

## `> ./listar_desafios`

| # | Task | Conceito |
|---|------|----------|
| 021 | Cadeia de caracteres | `len`, indexacao |
| 022 | Fatia a string | slicing `[a:b]` |
| 023 | Maiusculas e minusculas | `.upper()`, `.lower()`, `.title()` |
| 024 | Limpa o excesso | `.strip()`, `.lstrip()`, `.rstrip()` |
| 025 | Troca letra | `.replace()` |
| 026 | Separa e junta | `.split()`, `.join()` |
| 027 | Procura na string | `in`, `.find()`, `.count()` |
| 028 | Formata com estilo | f-string avancada |
| 029 | E numero ou letra? | `.isdigit()`, `.isalpha()`, `.isalnum()` |
| 030 | Validador de senha | mini-projeto |

## `> cat como_usar.md`
