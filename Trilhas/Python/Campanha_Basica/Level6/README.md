# Capitulo 6 - Funcoes

O salto de "escrever script" pra "escrever programa". Marco importante.
Neste capitulo a **CabanaTerminal** te ensina a organizar codigo em blocos
reutilizaveis.

## `> ./listar_desafios`

| # | Task | Conceito |
|---|------|----------|
| 051 | A primeira funcao | `def`, `return` |
| 052 | Recebe parametros | argumentos |
| 053 | Valor padrao | default args |
| 054 | Retorna cedo | `return` no meio |
| 055 | Escopo de variavel | local vs global |
| 056 | Funcao que chama funcao | composicao |
| 057 | Muitos argumentos | `*args`, `**kwargs` |
| 058 | Lambda: uma linha | `lambda` |
| 059 | Documenta a funcao | docstring |
| 060 | Calculadora com funcoes | mini-projeto |

## `> cat como_usar.md`

1. Leia o enunciado comentado no topo de cada `.py`.
2. Escreva seu codigo embaixo de `# >>> SEU CODIGO AQUI <<<`.
3. Rode com `python3 nome_do_arquivo.py`.
