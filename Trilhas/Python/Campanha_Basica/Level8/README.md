# Capitulo 8 - Arquivos e Persistencia

O programa passa a lembrar depois de fechar. Virada de chave.
Neste capitulo a **CabanaTerminal** te ensina a salvar e ler dados de verdade.

## `> ./listar_desafios`

| # | Task | Conceito |
|---|------|----------|
| 071 | Escreve no arquivo | `open()`, `write()` |
| 072 | Le o arquivo | `read()`, `readlines()` |
| 073 | Modo append | `'a'` |
| 074 | Bloco with | context manager |
| 075 | Le CSV | modulo `csv` |
| 076 | Escreve CSV | modulo `csv` |
| 077 | Salva em JSON | `json.dump()` |
| 078 | Le JSON | `json.load()` |
| 079 | Caminho de arquivo | `pathlib` |
| 080 | Agenda de contatos | mini-projeto |

## `> cat como_usar.md`

1. Leia o enunciado comentado no topo de cada `.py`.
2. Escreva seu codigo embaixo de `# >>> SEU CODIGO AQUI <<<`.
3. Rode com `python3 nome_do_arquivo.py`.
