# Capitulo 5 - Dicionarios e Conjuntos

Pares chave-valor e colecoes sem repeticao - a base de banco de dados e API.
Neste capitulo a **CabanaTerminal** te mostra como modelar dados de verdade.

## `> ./listar_desafios`

| # | Task | Conceito |
|---|------|----------|
| 041 | Chave e valor | `dict` basico |
| 042 | Acessa e adiciona | `.get()`, `.setdefault()` |
| 043 | Percorre o dicionario | `.keys()`, `.values()`, `.items()` |
| 044 | Remove do dicionario | `pop`, `del`, `clear` |
| 045 | Dicionario aninhado | `dict` dentro de `dict` |
| 046 | Contador de palavras | `dict` como acumulador |
| 047 | Conjunto: sem repeticao | `set` |
| 048 | Operacoes de conjunto | `union`, `intersection`, `difference` |
| 049 | Remove duplicatas | `set` + `list` |
| 050 | Cadastro de usuario | mini-projeto |
